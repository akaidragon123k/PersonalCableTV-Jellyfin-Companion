# Personal Cable TV Jellyfin Companion 0.1.0.1

## What's included

- Verified LG/webOS channel surfing during Personal Cable TV playback.
- Up changes to the previous/lower channel.
- Down changes to the next/higher channel.
- Cable-style transport restrictions remain active on verified LG/webOS playback:
  - Pause blocked
  - Rewind blocked
  - Fast-forward blocked
  - Seek/scrub blocked
  - Chapter skip blocked
- Personal Cable TV Guide and current-live behavior remain preserved.

## Known limitation

The Jellyfin Roku client does not currently support the Companion's full in-playback behavior. Up/Down channel surfing does not work and Pause may still be available. Roku users should use the dedicated P.Cable TV Companion Roku app.

## Compatibility

- Personal Cable TV: v0.5.3 baseline
- Jellyfin Server/Web: 10.11.10
- LG/webOS: verified
- Roku Jellyfin client: limited
