# Support

## Before asking for help

Please confirm:

- Personal Cable TV itself is installed and working.
- Jellyfin Live TV already receives Personal Cable TV M3U and XMLTV data.
- Your Jellyfin version is compatible with the Companion release.
- You restarted Jellyfin after installing or updating the plugin.

## Include in a bug report

- Companion version
- Jellyfin Server/Web version
- Client/device type (for example LG/webOS, browser, or Roku Jellyfin client)
- What you expected to happen
- What actually happened
- Screenshots or error messages when useful

Do **not** post passwords, API keys, access tokens, private credentials, or copyrighted media.

## Known Roku Jellyfin-client limitation

The Jellyfin Roku client does not currently provide the same Companion playback behavior verified on LG/webOS. For the full Roku cable-style experience, use the dedicated P.Cable TV Companion Roku app once it is publicly available.
