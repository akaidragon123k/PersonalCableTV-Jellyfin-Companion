# Notices

Personal Cable TV Jellyfin Companion is an unofficial companion for Jellyfin and is not endorsed by the Jellyfin Project.

This Companion package targets Jellyfin Server/Web 10.11.10 and uses Personal Cable TV Companion server plugin assembly version 0.1.0.1.

The Companion is designed to be removable as a Jellyfin plugin. It does not overwrite stock Jellyfin Web files and does not modify Personal Cable TV production data, M3U/XMLTV configuration, recordings, Jellyfin users, watch history, libraries, or NAS media.

Jellyfin Web is GPL-2.0-only. Companion-owned Web overlay files are under `web/pctv-overlay/`.

The package preserves the verified artwork fallback, remote navigation, Guide layout, current-live tuning, and Personal Cable TV-specific cable transport behavior used with Personal Cable TV v0.5.3.
